Welcome! Let's set up in 3 quick steps.

The app needs two free-to-create accounts: one that turns speech into text (Deepgram), one that writes the answers (Anthropic). You paste one key from each — that's the whole setup.
What does it cost? Both services bill only for what you use. A typical 1-hour interview costs about $0.30–$0.80 total. Deepgram gives new accounts free credit to start.
How do I get this key?
  1. Open console.deepgram.com/signup and create a free account (Google sign-in works).
  2. You start with free credit — no card needed at first.
  3. In the left menu click API Keys → Create a New API Key.
  4. Give it any name, click Create, then copy the key and paste it above.
How do I get this key?
  1. Open console.anthropic.com and create an account.
  2. Add a small amount of credit under Billing (e.g. $5 — lasts many interviews).
  3. Go to API Keys → Create Key.
  4. Copy the key (it's shown only once) and paste it above.
